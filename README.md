# The Funniest Honest Appliance Error

> ERROR: Stuck under the sofa since Tuesday. The cat has walked past me 214 times. It has not helped once.

`main.ts` holds the entry as a single constant, validates it (1–200 characters, one line, no control characters, not only whitespace), then writes it with no trailing newline to `entry.txt` inside `process.env.MAKEFUN_OUTPUT_DIR` (default `/output`), creating the directory if needed, and logs the character count.
